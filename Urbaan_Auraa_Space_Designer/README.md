# Urbaan Auraa Space Designer

A beginner-friendly Streamlit application with seven pages:
1. Home
2. Gallery
3. Design Details
4. Plot Planner
5. Price Estimator
6. Construction Budget
7. About Us

## Run on Windows

1. Install Python 3.11+ from https://www.python.org/downloads/ if needed.
2. Extract this ZIP.
3. Open the extracted `Urbaan_Auraa_Space_Designer` folder in VS Code.
4. Open Terminal → New Terminal.
5. Run:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Streamlit will show a local URL, usually http://localhost:8501.
