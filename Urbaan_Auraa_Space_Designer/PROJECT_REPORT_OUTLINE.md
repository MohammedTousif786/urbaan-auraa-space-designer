# Project Report Outline — Urbaan Auraa Space Designer

## Abstract
Urbaan Auraa Space Designer is a Streamlit-based home and interior design planning application. It combines design inspiration with basic plot-area calculations, indicative property estimate inputs, and construction budget planning.

## Objectives
- Provide a room-wise design inspiration gallery.
- Show design descriptions, suggested materials, and indicative budgets.
- Calculate plot area from length and width.
- Offer a clearly labelled illustrative property estimate.
- Estimate a rough construction budget with a cost breakdown.
- Present company/about information and contact details.

## Technology
- Python
- Streamlit
- HTML/CSS styling embedded in Streamlit
- Unsplash-hosted sample photos

## Limitations
The app is an educational prototype. It does not generate approved architectural drawings or use a validated Indian property valuation model. Local rates, building rules, site conditions, and professional advice must be checked separately.
